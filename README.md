# 金瓶梅·版本集

《金瓶梅》明清两代三大版本系统中的两种**完整公版文本**。

## 版本说明

| 版本 | 文件 | 底本 | 特点 |
|------|------|------|------|
| 词话本（万历本） | `词话本/金瓶梅詞話-萬曆足本.txt` | 明万历四十五年《新刻金瓶梅词话》（大安影印本） | 现存最早刻本，100回，语言质朴，多方言俚语 |
| 崇祯本（绣像本） | `崇祯本/金瓶梅-崇祯本.txt` | 明崇祯年间《新刻绣像批评金瓶梅》 | 文人润色本，文字规范，文学性更强 |

第三大系统「张竹坡批评本」（清初）目前仅有扫描图像，无公开文本版，故未收录。

## 来源

- 词话本：Internet Archive（源自维基文库大安本），公有领域
- 崇祯本：维基文库（明代原文，公有领域），经 API 整理为单文件

## 版权

原著为明代作品（兰陵笑笑生，约1610年前后），已进入公有领域。本项目仅收录公版原文，不含现代整理者的注释、校勘、标点版权内容。
